# Super Bingo Online

**O melhor bingo virtual com prêmios reais!**

## 📝 Sobre o Projeto
Super Bingo Online é um jogo de bingo virtual que oferece diversão e prêmios reais. Ideal para os amantes de bingo que querem jogar de forma prática e interativa.

### 🚀 Funcionalidades
- Comprar cartelas por **R$ 5,00**.
- Prêmio por uma linha completa: **R$ 5,00**.
- Painel com números sorteados e histórico.
- Saldo e controle de prêmios acumulados.
- Interface amigável e fácil de usar.

### 🎮 Como Jogar
1. **Compre uma ou mais cartelas**: Cada cartela custa R$ 5,00.
2. **Inicie o jogo**: Os números serão sorteados automaticamente.
3. **Complete uma linha** para ganhar o prêmio.

## 📊 Tecnologias Utilizadas
- **Frontend**: React.js.
- **Backend**: Node.js.
- **Deploy**: Vercel.
